Introduction

Analogia is a language for building and running hydraulic analog computers like MONIAC (the Phillips machine). Tanks hold a quantity, pipes move it, and RUN lets time flow continuously.

A program is a whitespace-separated sequence evaluated left to right (postfix). Numbers, strings and blocks are pushed on the stack; a name runs its word.

Each sample's Open in Playground button loads the first row's code into the editor. The Expected column shows the top of the stack after running the rows so far, as the Stack area draws it.

1 Values

Numbers are continuous quantities (double-precision floats): 1/4, 0.25 and 2e-3 all read. The Stack area shows them as fractions of up to six decimal places, marked ≈ when rounded. Strings are single-quoted; TRUE, FALSE and NIL are values too. [ ... ] is a block that is not run: it becomes a pipe's rate or a User word's body.

Sample codeExpectedNotes
0.1 0.2 ADD ≈ 3/10 A floating-point sum carries a tiny error, so it is marked ≈.
1 3 DIV ≈ 333333/1000000 Rounded, so it is marked ≈.
[ BATH 0.1 MUL ] [ BATH 1/10 MUL ] A block: its names are not run.

2 Arithmetic and comparison

ADD, SUB, MUL, DIV, MIN and MAX take two numbers (element by element when one is a Vector). EQ, LT and GT answer a Boolean, and condition a b IF leaves a when the condition holds, else b. DUP, DROP and SWAP work the stack; PRINT writes to the Output area.

Sample codeExpectedNotes
3 4 ADD 7/1
[ 1 2 3 ] 10 MUL [ 10/1 20/1 30/1 ] A number pairs with every element.
3 5 MIN 3/1
2 1 GT 10 0 IF 10/1 2 > 1, so 10.

3 Tanks and pipes

level 'NAME' TANK declares a tank (a stock, an integrator). [ rate ] 'FROM' 'TO' 'NAME' PIPE connects two tanks with a pipe; 'OUTSIDE' is the world beyond the model. A pipe only moves water, so the total is conserved unless a pipe touches the outside. Declaring the same name again refills or replaces it, so running a script twice does not double the plumbing. Inside a rate block a tank's name reads its level and a pipe's name its flow. An empty tank lets nothing out.

Sample codeExpectedNotes
100 'BATH' TANK [ 5 ] 'OUTSIDE' 'BATH' 'TAP' PIPE [ BATH 0.1 MUL ] 'BATH' 'OUTSIDE' 'DRAIN' PIPE DRAIN 10/1 The drain's flow now: a tenth of 100.
BATH 100/1 A tank's name pushes its level.

4 RUN and time

duration dt RUN lets the machine flow in continuous time (fourth-order Runge–Kutta). The Output area shows each tank's course as a sparkline, each pipe's final flow and the total in the tanks. The clock carries on, so several RUNs can change a parameter part way. TIME reads the clock; REWIND refills every tank to its declared level and sets the clock to 0.

Sample codeExpectedNotes
100 'BATH' TANK [ 5 ] 'OUTSIDE' 'BATH' 'TAP' PIPE [ BATH 0.1 MUL ] 'BATH' 'OUTSIDE' 'DRAIN' PIPE 30 0.1 RUN BATH ≈ 52489353/1000000 The level approaches 50, where inflow and outflow balance.
TIME 30/1
REWIND BATH 100/1

5 Cams and conditions

x [ x0 y0 x1 y1 ... ] CAM reads a value off a piecewise-linear curve, like the cams cut for MONIAC (held flat beyond its ends). TIME with IF makes a valve that opens at a given moment.

Sample codeExpectedNotes
5 [ 0 0 10 1 ] CAM 1/2
20 [ 0 0 10 1 ] CAM 1/1 Flat beyond the end.
0 'POOL' TANK [ TIME 5 GT 2 0 IF ] 'OUTSIDE' 'POOL' 'VALVE' PIPE 10 0.1 RUN POOL ≈ 9966667/1000000 2 per unit time flows in from t = 5: about 10.

6 User words

DEF takes a block and a name and defines a User word, listed in the Dictionary panel: use it for policy parameters and shared expressions. DEL deletes one, but refuses while another word or a pipe still uses it.

Sample codeExpectedNotes
[ 0.25 ] 'TAX-RATE' DEF 100 TAX-RATE MUL 25/1 TAX-RATE is added to the Dictionary panel.

7 A MONIAC-style economy

Five tanks (firms, households, treasury, idle balances, abroad) joined by eight pipes flow for 50 periods; then a tax cut, and 50 more. Investment is the idle balances times a rate read off a cam. The total water (money) stays at 1000. The same program is examples/moniac.alg in the repository.
