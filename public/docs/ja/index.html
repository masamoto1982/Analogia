はじめに

Analogia は、MONIAC（フィリップス機）のような流体式アナログコンピュータを組み立てて動かす言語です。タンクに量が貯まり、パイプがそれを流し、RUN で連続時間のまま時間を進めます。

プログラムは空白で区切った要素の並びで、左から順に評価されます（後置記法）。数値・文字列・ブロックはスタックに積まれ、名前はそのワードを実行します。

各例の Playground で開く ボタンで最初の行のコードをエディタに読み込めます。期待値 列は、その行までを実行したあとのスタックの先頭を Stack エリアの表示どおりに示します。

1 値

数値は連続量（倍精度の浮動小数点数）です。1/4、0.25、2e-3 と書けます。Stack エリアでは小数 6 桁までの分数で表示し、丸めたときは ≈ が付きます。文字列はシングルクォートで囲み、TRUE・FALSE・NIL も値です。[ ... ] は実行されないブロックで、パイプの流量式やユーザーワードの本体になります。

サンプルコード期待値備考
0.1 0.2 ADD ≈ 3/10 浮動小数点数の和なので、ごくわずかな誤差があり ≈ が付きます。
1 3 DIV ≈ 333333/1000000 丸めたので ≈ が付きます。
[ BATH 0.1 MUL ] [ BATH 1/10 MUL ] ブロック。名前は実行されずに残ります。

2 算術と比較

ADD・SUB・MUL・DIV・MIN・MAX は 2 つの数値を取ります（どちらかが Vector なら要素ごと）。EQ・LT・GT は真偽値を返し、条件 a b IF は条件が真なら a、偽なら b を残します。DUP・DROP・SWAP はスタックを操作し、PRINT は Output エリアに書きます。

サンプルコード期待値備考
3 4 ADD 7/1
[ 1 2 3 ] 10 MUL [ 10/1 20/1 30/1 ] 数値は各要素と組になります。
3 5 MIN 3/1
2 1 GT 10 0 IF 10/1 2 > 1 なので 10。

3 タンクとパイプ

水位 '名前' TANK はタンク（ストック、積分器）を宣言します。[ 流量 ] '流出元' '流入先' '名前' PIPE はタンクの間をパイプでつなぎます。'OUTSIDE' はモデルの外の世界です。パイプは量を移すだけなので、外界に触れない限り全体の量は保存されます。同じ名前でもう一度宣言すると入れ直し・付け替えになるので、スクリプトを何度実行しても配管は増えません。流量ブロックの中ではタンク名がその時点の水位を、パイプ名がその時点の流量を読みます。空のタンクからは流れません。

サンプルコード期待値備考
100 'BATH' TANK [ 5 ] 'OUTSIDE' 'BATH' 'TAP' PIPE [ BATH 0.1 MUL ] 'BATH' 'OUTSIDE' 'DRAIN' PIPE DRAIN 10/1 排水口の今の流量（水位 100 の 1 割）。
BATH 100/1 タンク名は水位を積みます。
Playground で開く

4 RUN と時間

期間 刻み RUN は機械を連続時間で流します（4 次のルンゲ＝クッタ法）。Output エリアに各タンクの推移のスパークライン、各パイプの最終流量、全体の水量を表示します。時計は続きから進むので、RUN を重ねて途中でパラメータを変えられます。TIME は時計を読み、REWIND は全タンクを宣言時の水位に戻して時計を 0 にします。

サンプルコード期待値備考
100 'BATH' TANK [ 5 ] 'OUTSIDE' 'BATH' 'TAP' PIPE [ BATH 0.1 MUL ] 'BATH' 'OUTSIDE' 'DRAIN' PIPE 30 0.1 RUN BATH ≈ 52489353/1000000 水位は 50（流入と流出が釣り合う点）に近づきます。
TIME 30/1
REWIND BATH 100/1

5 カムと条件

x [ x0 y0 x1 y1 ... ] CAM は MONIAC のカム板のように、区分線形の曲線から値を読みます（両端の外は一定）。TIME と IF を組み合わせると、ある時刻から開くバルブが書けます。

サンプルコード期待値備考
5 [ 0 0 10 1 ] CAM 1/2
20 [ 0 0 10 1 ] CAM 1/1 曲線の端より先は一定。
0 'POOL' TANK [ TIME 5 GT 2 0 IF ] 'OUTSIDE' 'POOL' 'VALVE' PIPE 10 0.1 RUN POOL ≈ 9966667/1000000 t = 5 から毎時 2 流れ込み、約 10 になります。
Playground で開く

6 ユーザーワード

DEF はブロックと名前を取ってユーザーワードを定義し、Dictionary パネルに並べます。政策パラメータや共通の式に使います。DEL は削除しますが、他のワードやパイプが使っている間は拒否します。

サンプルコード期待値備考
[ 0.25 ] 'TAX-RATE' DEF 100 TAX-RATE MUL 25/1 TAX-RATE が Dictionary パネルに追加されます。

7 MONIAC 風の経済

企業・家計・国庫・遊休残高・海外の 5 つのタンクを 8 本のパイプでつなぎ、50 期間流したあとで減税してさらに 50 期間流します。投資は遊休残高をカムに通した割合で決まります。全体の水量（お金）は 1000 のまま保たれます。リポジトリの examples/moniac.alg と同じものです。

サンプルコード期待値備考
# MONIAC 風の国民経済モデル。水 = お金。 # タンクに貯まり、パイプを流れ、全体の水量はパイプが外界に触れない限り変わらない。 # 政策パラメータ（ユーザーワード。Dictionary パネルに並ぶ） [ 0.25 ] 'TAX-RATE' DEF [ 0.15 ] 'SAVING-RATE' DEF [ 0.08 ] 'IMPORT-RATE' DEF # タンク（ストック） 400 'FIRMS' TANK # 企業：生産と売上 200 'HOUSEHOLDS' TANK # 家計：手元の所得 100 'TREASURY' TANK # 国庫 200 'SAVINGS' TANK # 遊休残高（貯蓄） 100 'FOREIGN' TANK # 海外 # パイプ（フロー）：[ 流量 ] '流出元' '流入先' '名前' PIPE [ FIRMS 0.5 MUL ] 'FIRMS' 'HOUSEHOLDS' 'INCOME' PIPE [ INCOME TAX-RATE MUL ] 'HOUSEHOLDS' 'TREASURY' 'TAX' PIPE [ HOUSEHOLDS SAVING-RATE MUL ] 'HOUSEHOLDS' 'SAVINGS' 'SAVING' PIPE [ HOUSEHOLDS IMPORT-RATE MUL ] 'HOUSEHOLDS' 'FOREIGN' 'IMPORTS' PIPE [ HOUSEHOLDS 0.6 MUL ] 'HOUSEHOLDS' 'FIRMS' 'CONSUMPTION' PIPE [ TREASURY 0.3 MUL ] 'TREASURY' 'FIRMS' 'SPENDING' PIPE [ FOREIGN 0.2 MUL ] 'FOREIGN' 'FIRMS' 'EXPORTS' PIPE # 投資：遊休残高が多いほど金利が下がり、投資の割合が上がる（MONIAC のカム） [ SAVINGS DUP [ 0 0.02 200 0.1 400 0.2 ] CAM MUL ] 'SAVINGS' 'FIRMS' 'INVESTMENT' PIPE # 50 期間流す 50 0.1 RUN # 減税してさらに 50 期間。流れは止めずに続きから [ 0.1 ] 'TAX-RATE' DEF 50 0.1 RUN Output エリアに 2 回分の推移が表示されます。
